# 7aggag.github.io

Portfolio of Mohamed Haggag, Senior iOS Developer, live at **https://7aggag.github.io**.

A single hand-written `index.html` styled as an Xcode window in the Default (Dark) theme. No build step, no frameworks.
The phone animation (`assets/phone.svg`) is generated by `tools/build_assets.py` in the [7aggag/7aggag](https://github.com/7aggag/7aggag) profile repo.
